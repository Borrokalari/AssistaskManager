# Assistask Manager

**Purpose of Assistask:**

Assistask was developed to help me manage my day to day tasks at my job; I want to quickly mark down tasks that I will need to do shortly and quickly see what's at the top of my priority list.

The same thing probably happens to you too: you have soo many meetings and you take so many notes that at some point some things are bound to get lost and / or forgotten.

Assistask is meant to help me minimize those lost and / or forgotten elements.
